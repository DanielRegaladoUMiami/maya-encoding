# Contributing

We welcome contributions to maya-encoding! See [CONTRIBUTING.md](https://github.com/DanielRegaladoUMiami/maya-encoding/blob/main/CONTRIBUTING.md) for the full guide.

## Quick Start

```bash
git clone https://github.com/DanielRegaladoUMiami/maya-encoding.git
cd maya-encoding
pip install -e ".[dev]"
pytest
ruff check .
```

## Development Workflow

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run tests: `pytest`
5. Run linter: `ruff check .`
6. Submit a pull request
